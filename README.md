🌌 Project Overview

A real-time space exploration game built with Godot 4.4.1, where players navigate between planets and planetary systems in a dynamic 3D universe.

The game integrates an SSVEP-based brain-computer interface (BCI), allowing players to control movement using visual attention. By focusing on flickering stimuli, users can move left, right, and across different planetary systems in real time.

Designed as both an interactive experience and a foundation for future expansion, the project combines game development with neurotechnology to explore new ways of human-computer interaction.
